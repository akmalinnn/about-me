### PostgreSQL デプロイ自動化
**Category:** インフラ
**Date:** 2021年8月 - 2025年8月
**Tech:** Terraform, Jenkins, GitLab

- Terraform で PostgreSQL のユーザー・ロールプロビジョニングを自動化し、手動でのデータベース管理を削減。
- Terraform を Jenkins と GitLab に統合し、複数のユーザーロール環境で検証・プランニング・デプロイを自動化。
- 承認ゲートと Terraform ステートの自動バックアップを実装し、デプロイの制御を強化して本番リスクを低減。

### CI/CD パイプライン強化
**Category:** CI/CD
**Date:** 2025年11月 - 2026年5月
**Tech:** Jenkins, GitLab CI, Docker

- デプロイ前に脆弱性を検出するため、SAST と DAST のセキュリティチェックを CI/CD パイプラインに組み込み。
- Zabbix と SigNoz を使い、パイプラインデプロイにモニタリングとトレーシングの統合を追加。
- コンテナアプリケーションのビルド・テスト・デプロイの各ステージを複数環境で自動化。
