### インフラ自動化
**Icon:** automation

Bash、Go、Python スクリプトでサーバー運用を自動化 — バックアップスケジュール、ログローテーション、反復的な運用タスクを信頼性の高いパイプラインに変換。

### コンテナ化と CI/CD
**Icon:** container

Docker でコンテナアプリケーションをデプロイし、Jenkins と GitLab CI でビルド・デプロイ・検証をエンドツーエンドに自動化。

### モニタリングと可観測性
**Icon:** monitor

Zabbix・SigNoz・Grafana でモニタリング・トレーシング・アラートを構築し、ユーザーに影響が出る前にサービス問題を検出・解決。

### クラウドと Infrastructure as Code
**Icon:** cloud

Terraform でインフラを構築し、CI/CD と承認ゲートに統合して、複数環境での検証とデプロイを自動化。
